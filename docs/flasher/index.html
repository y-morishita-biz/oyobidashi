M5Dial に呼び出しボタンを書き込む

パソコンの Chrome か Edge で、このページから M5Dial にファームウェアを書き込めます。ツールのインストールは要りません。

⚠️ このページは、作者が実機で動作を確かめていないトライアル版です。ここでの書き込みと、配布しているファームウェアの設定モードは「おまけ」として用意したもので、うまく動かないことがあります。確実に使いたいときは、作者が実機で確かめた自分でビルドする手順を使ってください。

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。 安全な接続（https）で開いてください。

M5Dial を USB-C ケーブルでつないでから押してください

手順

  1. M5Dial を、データ通信ができる USB-C ケーブルでパソコンにつなぐ（充電専用のケーブルだと見つかりません）
  2. 上の「書き込む」を押し、出てきた一覧から M5Dial を選んで「接続」を押す（名前は USB JTAG/serial debug unit などと出ます）
  3. 「Install oyobidashi call-button」を押す
    • はじめて書き込むとき：「Erase device」（本体を消す）にチェックを入れる
    • 新しい版に入れ替えるとき：チェックを外したままにすると、Wi-Fi などの設定が残ります
  4. 「Installation complete!」と出たら閉じる。M5Dial が再起動しないときは、USB ケーブルを抜いて挿し直す
  5. M5Dial の画面に「設定モード」と QR コードが出たら、書き込みは完了です。続きは設定ガイドを見てください

何度やっても M5Dial が一覧に出ないときは、ケーブルを替えてみてください。それでもだめなときは、M5Dial の公式ドキュメントで書き込みモード（ダウンロードモード）での起動のしかたを確かめてから、もう一度試してください。

# かんたんセットアップ（配布しているファームウェアを使う）

部材がそろっていれば、**ツールのインストールもプログラムの書き換えもなしで**呼び出しボタンを用意できます。パソコンのブラウザで M5Dial に書き込み、そのあとの設定はスマホから行います。

かかる時間の目安は 20分 です。

> 製品カードを出したい、画面の文言を変えたいなど、自分用に手を入れたいときは [ファームウェアを自分でビルドする](firmware.md) を見てください。

## 用意するもの

| もの | 用途 |
|---|---|
| [M5Dial](https://docs.m5stack.com/ja/core/M5Dial) | 呼び出しボタン本体 |
| USB-C ケーブル（**データ通信ができるもの**） | パソコンと M5Dial をつなぐ。充電専用のケーブルだとパソコンが M5Dial を見つけられません |
| パソコン（Windows / macOS）と **Chrome か Edge** | ファームウェアの書き込み。Safari と Firefox は書き込みに対応していません |
| ブースに置くスマホ | テザリングで M5Dial をネットにつなぐ |
| 持ち歩くスマホ | ntfy アプリで通知を受け取る |
| モバイルバッテリー | 会場での電源 |

## 全体の流れ

```mermaid
flowchart LR
    A["1. テザリングを<br>用意する"] --> B["2. パソコンの<br>ブラウザで書き込む"]
    B --> C["3. スマホで<br>M5Dial を設定"]
    C --> D["4. ntfy アプリで<br>購読する"]
    D --> E["5. 触れて<br>確かめる"]
```

## 1. ブース用スマホのテザリングを用意する

M5Dial は **2.4GHz** の Wi-Fi にしかつながりません。[テザリング設定](tethering.md) を見て、ブースに置くスマホのテザリングの名前（SSID）とパスワードを決めておいてください。

## 2. パソコンのブラウザで M5Dial に書き込む

1. M5Dial を USB-C ケーブルでパソコンにつなぐ
2. パソコンの Chrome か Edge で **[書き込みページ](https://y-morishita-biz.github.io/oyobidashi/)** を開く
3. **書き込む** を押し、出てきた一覧から M5Dial を選んで **接続** を押す
   - 名前は `USB JTAG/serial debug unit` などと出ます。M5Dial を抜くと一覧から消えるものが M5Dial です
4. **Install oyobidashi call-button** を押す
   - はじめて書き込むときは **Erase device**（本体を消す）にチェックを入れる
5. 「Installation complete!」と出たら閉じる。数十秒かかります
6. M5Dial の画面が変わらないときは、USB ケーブルを抜いて挿し直す

白い画面に **「設定モード」と QR コード** が出れば、書き込みは完了です。

<details>
<summary>コマンドで書き込みたい人へ（esptool）</summary>

[リリースのページ](https://github.com/y-morishita-biz/oyobidashi/releases/latest) から `oyobidashi-call-button-<バージョン>.bin` をダウンロードして、次を実行します。Python が入っていれば、Linux でも使えます。

```sh
pip install esptool
```

```sh
esptool.py --chip esp32s3 write_flash 0x0 oyobidashi-call-button-<バージョン>.bin
```

このファイルは本体の先頭から書き込むので、**保存してある設定（テザリング・トピック名）は消えます**。書き込んだあとは、もう一度 3. の設定をしてください。

</details>

### 書き込めないとき

- 一覧に M5Dial が出ない：ケーブルを替えてみる（充電専用ケーブルのことが多いです）。USB ハブを使っているなら、パソコンに直接つなぐ
- 「Failed to connect」などで止まる：もう一度「書き込む」から試す
- それでもだめなとき：[M5Dial の公式ドキュメント](https://docs.m5stack.com/ja/core/M5Dial) で書き込みモード（ダウンロードモード）での起動のしかたを確かめてから、もう一度試す

## 3. スマホで M5Dial を設定する

ここからはパソコンは要りません。M5Dial は USB ケーブルかモバイルバッテリーで電源につないだままにしておきます。

ブース用のスマホと持ち歩くスマホ、どちらで設定してもかまいません。

1. ブース用スマホの**テザリングをオン**にしておく（M5Dial がテザリングを探せるように）
2. M5Dial の画面の QR コードを、スマホのカメラで読み取る
   - 「ネットワーク "oyobidashi-XXXX" に接続」と出るので、接続する
   - QR コードが読めないときは、スマホの Wi-Fi 設定で画面の下に出ている `oyobidashi-XXXX` を選び、`PASS` のあとの8文字をパスワードに入れる
3. つながると、スマホに設定の画面が開く（M5Dial の画面は黒になり「スマホの画面で設定を続けてください」と出ます）
   - 開かないときは、スマホのブラウザで `http://192.168.4.1/` を開く
4. 設定の画面で、次を入れる

| 項目 | 入れるもの |
|---|---|
| テザリングの名前（SSID） | 1. で決めたテザリングの名前。入力欄を押すと、近くの Wi-Fi が候補に出ます |
| テザリングのパスワード | テザリングのパスワード |
| ntfy のトピック名 | **最初から入っているランダムな名前のままでかまいません**。通知の合言葉になります |
| QR コードの行き先（なくてもよい） | 来場者を待たせているときに画面に出す URL（自分の SNS やサイト）。空にすると QR コードは出ません |
| QR コードの下の文字（なくてもよい） | QR コードの下に小さく出す文字。半角英数字だけ使えます（例：`example.com`） |

5. **保存して再起動する** を押す
6. 次の画面に出る **トピック名を控える**（「コピーする」を押して、メモやパスワードマネージャーに貼り付ける）。次の手順で使います

M5Dial は再起動して、テザリングにつながります。オレンジの「TAP」の画面になり、画面のいちばん下に小さな点が出ていなければ、つながっています。

> スマホは自動で元の Wi-Fi（またはモバイル回線）に戻ります。戻らないときは、スマホの Wi-Fi 設定で `oyobidashi-XXXX` から切り替えてください。

## 4. 持ち歩くスマホで ntfy アプリを設定する

[通知を受け取るスマホの設定](receiver-ntfy.md) の手順で ntfy アプリを入れ、**3. で控えたトピック名** を購読します。

## 5. 触れて確かめる

1. M5Dial の画面に触れる →「呼び出しています」→「制作者に届きました」と変わる
2. 持ち歩くスマホに「ブースで呼ばれています」と通知が届く
3. 通知を長押しして「向かいます」を押す → M5Dial に「制作者が向かっています」と出る
4. M5Dial の画面を3秒長押しして、待機に戻す

ここまでできたら準備は完了です。展示会の当日は [当日のチェックリスト](event-checklist.md) を使ってください。

## 設定をやり直したいとき

テザリングを変えた、トピック名を作り直したい、トピック名を忘れた、というときは、**M5Dial の画面を押したまま USB ケーブル（電源）を挿し直す** と設定モードに入れます。画面が白くなって QR コードが出たら、指を離してください。

- 設定の画面には、今の設定が入った状態で開きます。テザリングのパスワードは、変えないなら空のままでかまいません
- 設定を変えずにやめるときは、M5Dial の画面を3秒長押しします（元の設定のまま再起動します）

## 新しい版に入れ替えるとき

[書き込みページ](https://y-morishita-biz.github.io/oyobidashi/) で、2. と同じように書き込みます。**Erase device のチェックを外したまま** にすると、設定は残ります。（esptool で書き込むと設定は消えるので、3. の設定をやり直してください）

## M5Dial を人に譲るとき・使わなくなったとき

テザリングのパスワードとトピック名は M5Dial の中に保存されています。書き込みページで **Erase device にチェックを入れて** 書き込み直すと消えます（[SECURITY.md](../../SECURITY.md)）。

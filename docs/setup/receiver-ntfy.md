# 3. 通知を受け取るスマホの設定（ntfy アプリ）

持ち歩くスマホに [ntfy](https://ntfy.sh/) のアプリを入れて、M5Dial と同じトピックを購読します。アカウント登録は要りません。

## iPhone

1. App Store で [ntfy](https://apps.apple.com/jp/app/ntfy/id1625396347) を入れる
2. アプリを開いて、通知を**許可**する
3. 右上の **＋** をタップし、トピック名に M5Dial と同じ文字列（設定モードの最後に出たトピック名、または `secrets.h` の `NTFY_TOPIC`）を入れて購読する
   - 「Use another server」はオフのまま（ntfy.sh を使う）
   - 返事用の `-reply` のトピックは購読しなくて大丈夫です
4. M5Dial の画面に触れて、通知が届くか確かめる

### 返事のしかた

通知を**長押し**すると、返事のボタンが出ます。

| ボタン | M5Dial の画面 |
|---|---|
| 向かいます | 「制作者が向かっています」（5分で待機に戻る） |
| 5分で戻ります | 「12:15 ごろ戻ります」のように戻る時刻を表示 |
| 30分で戻ります | 同上 |

通知をタップしてアプリを開くだけでは返事になりません（うっかり返事しないようにしています）。

### 気づきやすくする

会場は騒がしいので、通知に気づける設定にしておきます。

- **設定 → 通知 → ntfy**：「通知を許可」「サウンド」「バナー（持続的）」をオン
- 集中モードを使う人は、**設定 → 集中モード →（使うモード）→ App** で ntfy を「通知を許可」に追加する
- Apple Watch を使っているなら、ntfy の通知がミラーされるか確かめておくと、ポケットの中でも気づけます

> 集中モード中に届くかどうかは、使っているモードの設定によって変わります。本番前に一度、集中モードをオンにした状態で試してください。

### Mac を使っている人は「Mac に表示」をオフにする

iPhone の通知を Mac にも出す設定（iPhone ミラーリング）を使っていると、ntfy の通知が iPhone の画面に出ないことがあります。iPhone がロック中で、近くの Mac を使っているとき、iPhone は通知を Mac に出して、自分の画面をつけません。iPhone は振動するだけで、通知は通知センターに入ったままになります。展示会の会場で Mac を開いていると、呼ばれたことに気づけません。

**設定 → 通知 → ntfy** で「**Mac に表示**」をオフにしてください。これで、Mac を使っているときも iPhone の画面に通知が出ます。

## Android

1. Google Play で [ntfy](https://play.google.com/store/apps/details?id=io.heckel.ntfy) を入れる
2. ＋ からトピックを購読する（iPhone と同じく、M5Dial と同じトピック名を入れる）
3. 通知の設定でサウンド・ポップアップを許可し、省電力の対象から外す（機種によっては「電池の最適化」「バックグラウンドの制限」）

返事のボタンは通知を下に引き出すと出ます。

## トピック名の扱い

- トピック名は**パスワードと同じ**です。知っている人は誰でも通知を読めて、M5Dial に偽の返事も送れます
- 展示会の写真や SNS に、ntfy アプリの画面（トピック名が写る）を載せないでください
- 漏れたかもしれないときは、新しいトピック名を作って M5Dial に入れ直し（設定モードの「作り直す」か `secrets.h`）、アプリで購読し直してください（[SECURITY.md](../../SECURITY.md)）

## 複数人で受け取る

同じトピックを購読すれば、何人でも同時に通知を受け取れます。誰かが返事のボタンを押すと、M5Dial の画面はその返事に切り替わります。

## 会場で設営するとき

- [ ] ブース用スマホのテザリングをオン（2.4GHz・自動オフなし）
- [ ] ブース用スマホと M5Dial をモバイルバッテリーにつなぐ
- [ ] M5Dial の画面の一番下に小さな点が出ていない（＝ Wi-Fi につながっている）
- [ ] 画面に触れて、持ち歩くスマホに通知が届く
- [ ] 通知を長押しして「向かいます」を押し、M5Dial に「向かっています」と出る
- [ ] 画面を3秒長押しして待機に戻す
- [ ] 担当者メニュー（画面に触れたままダイヤルを1段回して離す）で音量と画面の向きを合わせる

## 担当者メニューの使い方

| 操作 | 内容 |
|---|---|
| 在席にする | ブースにいるあいだ。触れられても通知しない（60分で自動で待機に戻る） |
| 離席にする | 待機に戻す |
| 15・30・60分で戻る | 画面に戻る時刻を出す。触れられると目立たない通知が来る |
| 音量・画面の向き | 本体に保存される |

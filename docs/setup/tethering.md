# 2. ブースに置くスマホのテザリング設定

M5Dial は、ブースに置いたスマホのテザリングでインターネットにつながります。会場の Wi-Fi は混雑して不安定なことが多いので、自分の回線を持ち込む方が確実です。

ブースに置くスマホは、Android でも iPhone でもかまいません。ただし、持ち歩く方とは別の端末にしてください。持ち歩く方でテザリングすると、ブースを離れた瞬間に M5Dial の回線が切れます。

## どの機種でも大事なこと

| 設定 | 理由 |
|---|---|
| 2.4GHz で飛ばす | M5Dial は 2.4GHz の Wi-Fi にしかつながりません。5GHz だけだと見つかりません |
| 自動でオフにならないようにする | 会期中に勝手にテザリングが切れるのを防ぎます |
| パスワードを長くランダムにする | 会場には大勢の人がいます。推測できるパスワードは避けてください |
| ネットワーク名（SSID）に本名や会社名を入れない | 周りの人の Wi-Fi 一覧に表示されます |
| 充電しながら使う | テザリングは電池の減りが早いです |

決めたネットワーク名とパスワードは、M5Dial に書き込む `secrets.h` にも入れます（[firmware.md](firmware.md#4-secretsh-を作る)）。**`secrets.h` 以外（メモアプリ・SNS に載せる写真など）には書かないでください**。 パスワードマネージャーの「パスワードを生成」機能で作って、そこに保存しておくのがおすすめです。

## Android の場合

メニューの名前は機種や Android のバージョンによって違います。以下は一例として、Google Pixel（Android 14 前後）での手順です。

1. **設定 → ネットワークとインターネット → アクセスポイントとテザリング → Wi-Fi アクセスポイント** を開く
2. **アクセスポイント名**：本名や会社名を含まない名前にする
3. **セキュリティ**：`WPA2-Personal` か `WPA2/WPA3-Personal` にする
   - `WPA3-Personal` だけにすると、M5Dial がつながらないことがあります。つながらないときは WPA2 を含む設定にしてください
4. **アクセスポイントのパスワード**：長くランダムなパスワードにする
5. **速度と互換性**（機種によっては「AP 帯域」）：**2.4 GHz** を選ぶ
6. **アクセスポイントを自動的に OFF にする**：**オフ**にする
7. 一番上のスイッチで Wi-Fi アクセスポイントをオンにする

Galaxy や Xperia などでは「テザリング」「モバイルホットスポット」「詳細設定」などの下に同じ項目があります。

## iPhone の場合

1. **設定 → 一般 → 情報 → 名前** で、本名を含まない名前に変える（これがネットワーク名になります）
2. **設定 → インターネット共有** を開く
3. **「Wi-Fi」のパスワード** を長くランダムなものに変える
4. **「互換性を優先」をオン** にする（これで 2.4GHz になります）
5. **「ほかの人の接続を許可」をオン** にする

iPhone のインターネット共有は、つながっている端末がしばらくないと自動でオフになることがあります。M5Dial がつながっているあいだは通常切れませんが、設営のときは **インターネット共有の画面を開いたまま M5Dial の電源を入れる** と確実につながります。

## Android と iPhone、どちらがいい？

どちらでも動きます。違いは次のくらいです。

| | Android | iPhone |
|---|---|---|
| 2.4GHz にする | 帯域を選ぶ（機種によって名前が違う） | 「互換性を優先」をオン |
| 自動オフ | 設定でオフにできる機種が多い | 設定項目はない。つながっていれば切れにくい |
| 料金プラン | テザリングが別料金・容量制限のプランがあるので確認する | 同左 |

通知1回の通信量は数 KB なので、1日使ってもデータ量はほとんど気にしなくて大丈夫です。

## つながらないとき

- M5Dial の画面の一番下に小さな点が出ているあいだは、Wi-Fi につながっていません。自動でつなぎ直します
- `secrets.h` のネットワーク名とパスワードを見直す（大文字小文字、前後の空白、全角文字が混ざっていないか）
- テザリングが 5GHz になっていないか確かめる
- それでもだめなときは [firmware.md の「ログを見たいとき」](firmware.md#ログを見たいとき) でログを見る。`[wifi] status ...` が繰り返し出るときは、ネットワーク名かパスワードが違うことが多いです

## 電源のおすすめ

2ポートのモバイルバッテリーに、M5Dial とブース用スマホを両方つなぐと配線がまとまります。スマホがつながっていると流れる電流が大きくなり、バッテリーの「電流が小さいと自動でオフ」も起きにくくなります。心配なら [battery-test](../../battery-test/README.md) で事前に試してください。

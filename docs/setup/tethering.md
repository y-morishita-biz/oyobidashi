# 2. ブースに置くスマホのテザリング設定

M5Dial は、ブースに置いたスマホのテザリング（Wi-Fi アクセスポイント）でインターネットにつながります。会場の Wi-Fi は混雑して不安定なことが多いので、自分の回線を持ち込む方が確実です。

## 大事なこと（どの機種でも共通）

| 設定 | 理由 |
|---|---|
| **2.4GHz で飛ばす** | M5Dial（ESP32-S3）は 2.4GHz にしかつながりません。5GHz や「6GHz」だけだと見つかりません |
| **つながっている端末がないと自動でオフ、を無効にする** | 会期中に勝手にテザリングが切れるのを防ぎます |
| **パスワードを長くランダムにする** | 会場には大勢の人がいます。推測できるパスワードは避けてください |
| **SSID（ネットワーク名）に本名や会社名を入れない** | 周りの人の Wi-Fi 一覧に表示されます |
| **充電しながら使う** | テザリングは電池の減りが早いです |

決めた SSID とパスワードは `call-button/include/secrets.h` の `WIFI_SSID` / `WIFI_PASS` に書きます（[firmware.md](firmware.md)）。**このファイル以外（README・メモ・SNS のスクリーンショットなど）には書かないでください。**

パスワードはパスワードマネージャーの生成機能や、次のコマンドで作れます。

```sh
openssl rand -base64 18
```

## Android の場合（作者の運用）

メニューの名前は機種や Android のバージョンによって違います。以下は Google Pixel（Android 14 前後）の例です。

1. **設定 → ネットワークとインターネット → アクセスポイントとテザリング → Wi-Fi アクセスポイント** を開く
2. **アクセスポイント名**：本名や会社名を含まない名前にする
3. **セキュリティ**：`WPA2-Personal` か `WPA2/WPA3-Personal` にする
   - `WPA3-Personal` だけにすると、M5Dial がつながらないことがあります。つながらないときは WPA2 を含む設定に戻してください
4. **アクセスポイントのパスワード**：上で作ったランダムなパスワード
5. **速度と互換性**（機種によっては「AP 帯域」）：**2.4 GHz** を選ぶ
6. **アクセスポイントを自動的に OFF にする**：**オフ**にする
7. Wi-Fi アクセスポイントをオンにする

Galaxy や Xperia などでは「テザリング」「モバイルホットスポット」「詳細設定」などの下に同じ項目があります。

## iPhone をブース用にする場合

持ち歩く方が Android で、ブースに iPhone を置く場合です。

1. **設定 → インターネット共有** で「ほかの人の接続を許可」をオン
2. **「互換性を優先」をオン**（これで 2.4GHz になります）
3. Wi-Fi のパスワードを長いものに変える
4. SSID は iPhone の名前になります。**設定 → 一般 → 情報 → 名前** で、本名を含まない名前に変えておくと安心です

iPhone のインターネット共有は、つながっている端末がしばらくないと自動でオフになることがあります。M5Dial は常につながっているので通常は切れませんが、M5Dial の電源を入れる前にインターネット共有の画面を開いておくと確実です。

## つながらないとき

- M5Dial の画面の一番下に小さな点が出ているときは、Wi-Fi が切れています。自動でつなぎ直します
- `secrets.h` の SSID・パスワードの大文字小文字、全角スペースが混ざっていないかを確かめる
- テザリングが 5GHz になっていないかを確かめる
- [firmware.md のシリアルログ](firmware.md#6-動いているか確かめる)に `[wifi] status ...` の行が出ます。何度も繰り返すときは SSID かパスワードの間違いが多いです

## 電源のおすすめ

2ポートのモバイルバッテリーに、M5Dial とブース用スマホを両方つなぐと配線がまとまります。スマホがつながっていると流れる電流が大きくなり、バッテリーの「電流が小さいと自動でオフ」も起きにくくなります。心配なら [battery-test](../../battery-test/README.md) で事前に試してください。

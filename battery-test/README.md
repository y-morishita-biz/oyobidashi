# battery-test

M5Dial をモバイルバッテリーにつなぎっぱなしにして、途中で給電が切れないか（バッテリーの自動オフに引っかからないか）を確かめるためのテスト用ファームウェア。

## 書き込み
1. VS Code + PlatformIO でこのフォルダ（`battery-test`）を開く
2. （任意）`include/secrets.example.h` を `include/secrets.h` にコピーして、テザリングの SSID / パスワードを入れる。本番と同じく Wi-Fi をつないだ状態で試せる
3. M5Dial を USB でつなぎ、Upload

## 画面と操作
| 表示 | 意味 |
|---|---|
| 中央の時刻 | 起動してからの経過時間 |
| 外周のリング | 秒の進み。止まっていたら固まっている |
| LAST | 前回の起動で動いていた時間（1分ごとに保存） |
| LCD / WiFi | 画面の明るさと Wi-Fi の状態（電波強度 dBm） |
| BOOT # | 起動回数 |

- ダイヤルを回す：画面の明るさ（0% にすると一番電流が小さい＝一番厳しい条件）
- 画面を短く押す：Wi-Fi のオン/オフ
- 画面を2秒長押し：LAST と起動回数をリセット

## テストの手順
1. 長押しで記録をリセットしてから、USB を抜いてモバイルバッテリーにつなぐ
2. 数時間（できれば展示会の1日分）放置する
3. ダイヤルを回して画面が明るくなれば生きている。反応がなければ給電が切れているので、バッテリーのボタンを押すかケーブルを抜き差しして再起動 → **LAST に、切れるまでに動いていた時間が出る**
4. 条件を変えて繰り返す（明るさ 0% / Wi-Fi オフが最も自動オフに引っかかりやすい）
